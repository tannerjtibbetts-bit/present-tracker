# Present Tracker

Keep track of the gifts you buy for each person, for Christmas, birthdays, Easter, Valentine's Day
and special occasions. Photograph what you ordered and the app reads the item, price, store, date
and order number. A fairness check compares spending and number of gifts, and each occasion makes
its own letter-style PDF (Dear Santa, Dear Easter Bunny, Dear Cupid).

Everything is saved on the phone. Built with Flutter for iPhone and Android.
